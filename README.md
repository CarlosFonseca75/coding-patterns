# 🧠 Coding Patterns

A hands-on collection of coding patterns and algorithm exercises.\*\*.

This repository is focused on learning how to **recognize, understand, and apply common problem-solving patterns** used in coding interviews.

The goal is not to memorize solutions, but to understand **why** a pattern works and **when** to use it.

The repository follows a pattern-based approach:

## 🧪 Running the Tests

Install dependencies:

```bash
pnpm install
```

Run all tests:

```bash
pnpm test
```

Run tests in watch mode:

```bash
pnpm test:watch
```

Run TypeScript type checking:

```bash
pnpm typecheck
```

## 🎯 Goal

The main goal of this project is to build a stronger foundation in algorithms and problem solving through consistent practice.

For each exercise, the focus is on understanding:

- How to identify the pattern
- Why the pattern fits the problem
- How to implement the solution
- How to test it
- How to recognize similar problems in the future
